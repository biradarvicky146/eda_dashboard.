# EDA Dashboard

## About
This project is an Exploratory Data Analysis (EDA) dashboard developed using Python.

## Features
- Data loading and cleaning
- Exploratory data analysis
- Data handling using Pandas
- Data visualization using charts
- Analysis of patterns and trends
- Interactive dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Objective
The main objective of this project is to analyze data, visualize important patterns, and present useful insights for better decision making.
